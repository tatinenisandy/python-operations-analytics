# Python Operations Analytics

A Python portfolio project demonstrating operational data analysis, KPI reporting and automated testing using synthetic support ticket data.

## Project Files

- `sample_tickets.csv` — Synthetic support ticket dataset
- `report.py` — Python script for KPI calculations and reporting
- `test_report.py` — Automated tests for the reporting logic

## Skills Demonstrated

- Python programming
- CSV data processing
- KPI calculation
- Operational reporting
- Automated testing

## How to Run

1. Download or clone the repository.
2. Ensure Python 3 is installed.
3. Run `python report.py`.
4. Run `python -m unittest discover -v` to execute the tests.

## Data Privacy

This project uses synthetic data and does not contain confidential employer or customer information.
